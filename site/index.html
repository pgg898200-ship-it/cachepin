Where do your prompts split?

Two agents load the same tools in a different order. The second request can lose a reusable prefix. CachePin finds the first change and shows what a consistent order would recover.

Compare requests in your MCP client

Open the CachePin bundle in a client that supports MCPB extensions on macOS or Linux (x86-64 or ARM64). Call diagnose_diff with two serialized requests, prev_json and curr_json. The tool runs locally and returns the byte offset where the requests first differ.
